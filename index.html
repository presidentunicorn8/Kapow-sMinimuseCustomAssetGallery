Easy Download Option

1. Click the "Sync Local Game Data" button and paste the path based on if you are windows linux or android.

windows: %APPDATA%\Godot\app_userdata\MiniMuse
android: idk but somewhere in Internal Storage/Android/
linux: idk

2. Download the item you want.
3. Extract the zip file from your Downloads folder back into that game folder. Replace existing files with the new
4. If you skip these steps you can also download and import the assets layer by layer but its just a bit time-consuming.
